# qeve_cost
Gate count calculations for the paper "Accuracy and resource advantages of quantum eigenvalue estimation with non-Hermitian transcorrelated electronic Hamiltonians" (https://arxiv.org/abs/2511.21867)

The data is for arxiv v1. The Hamiltonians for arxiv v2 are slightly different, I'll update them as soon as I can. However, they should be more or less the same for gate costing purposes.
